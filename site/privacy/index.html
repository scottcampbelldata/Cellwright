Website privacy · Updated October 10, 2026

Website visits, without workbook data.

The public site explains Cellwright and links to downloads. Your workbooks stay in the local app.

What this website measures

Cloudflare Web Analytics reports website visits, page views, referring sites, countries, devices and page performance. Visit counts are an approximation, not a count of identified people.

A separate first-party endpoint stores daily aggregate page views, active reading seconds, download clicks and views that reach 75% of a page. It stores only the day, an allowlisted public page path and numeric totals. It does not store visitor IDs, cookies, IP addresses, full URLs, query strings, referrers, names or workbook data in the engagement database.

Active time counts only while the page is visible and focused, and pauses after one minute without interaction. It is an estimate; background tabs, blocked scripts, failed beacons and browsers closing abruptly can reduce recorded time. Mean active seconds per page view is different from total elapsed session length.

Browser choices

The first-party engagement script skips collection when Global Privacy Control or Do Not Track is enabled. It creates no cookies or browser-storage identifiers. Browser extensions may block either analytics system.

Hosting and data access

Cloudflare hosts the site and receives network requests necessary to deliver it. Cloudflare may process request metadata under its own service policies. Engagement totals are stored in a dedicated Cloudflare D1 database; the reporting console requires the owner's Cloudflare account. The public endpoint accepts writes only and exposes no reports.

The local application

The downloaded app scans and converts workbooks locally. This website has no workbook upload or macro-execution endpoint. Optional review exports are previewed and saved locally; users decide whether to share them. A consulting link does not transmit workbook data.
