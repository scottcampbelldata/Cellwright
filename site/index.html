  1. Extract the full archive.Python 3.11+ runs the dashboard; LibreOffice is needed for Basic/UNO conversion. Setup checks explain missing dependencies.
  2. Open the launcher.Use “Start Cellwright.cmd” on Windows or “start-cellwright.sh” on Linux to open the local dashboard.
  3. Scan demonstration workbook.Scan, create a candidate and inspect its checklist and source diff. Scanning and conversion never run macros.
  4. Review, then verify deliberately.Candidate generation and test results are separate. Routine execution requires a startup flag and consent for each comparison.

Clear about what still needs work.

Custom ActiveX controls, complex or dynamic forms, lifecycle events and unsupported code stay on the manual checklist. Skipped workbook parts stay marked as unknown. Form display and new Basic helper behavior are not runtime-verified, and effort ranges remain uncalibrated planning estimates.
