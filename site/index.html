Getting started

Start with the sample.
Bring your own next.

The archive includes everything Cellwright supplies: the scanner, local dashboard, migration tools and a sample workbook. Setup checks tell you which dependencies to install.

Read the complete migration guide →
  1. Extract the full archive.Python 3.11+ runs the dashboard. LibreOffice is needed for Basic/UNO conversion.
  2. Open the launcher.“Start Cellwright.cmd” on Windows. “start-cellwright.sh” on Linux. The dashboard opens in your browser.
  3. Scan the demonstration workbook.Create a candidate, inspect the checklist and compare its source. Scanning and conversion never run macros.
  4. Review, then verify deliberately.Execution requires a startup flag and consent for each comparison. A generated candidate is not a passed test.

Known limits

A useful start.
A result you still review.

Custom ActiveX controls, complex or dynamic forms, lifecycle events and unsupported code stay on the manual checklist. Skipped workbook parts stay marked as unknown.

Form display and new Basic helper behavior are not runtime-verified. Effort ranges remain uncalibrated planning estimates.
